# Multi-platform strategy — History of Science

YouTube remains the **pillar**. Every other platform is a discovery channel that should send viewers to the full History of Science documentary and brand.

## Output from one long-form video

| Asset | Target |
|-------|--------|
| Long-form YouTube | 1 |
| Short-form vertical clips | 4–8 |
| YouTube Shorts / TikTok / IG Reels / FB Reels | same core clips, customised metadata |
| X posts | 3–6 |
| Threads posts | 2–4 |

Do **not** create separate video files per platform unless a format difference is required. Reuse the clean 9:16 export.

## Canonical schedule (Europe/London)

Preserved from `00_Brand/Channel-Setup/OPTIMAL_PUBLISH_SCHEDULE.json`:

- Long-form: Thursday **19:00**
- Short #1: Thursday **21:00**
- Days 2–7 Shorts: **12:30**
- Cross-platform: same clip within 24h, staggered (+0 / +30 / +60 / +90 / +120 / +150 minutes)

Configurable in `07_Content-Ops/src/config/publishing-schedule.ts`.

## Soft CTAs only

Examples:

- Watch the full story on History of Science.
- The full explanation is on the channel.

Avoid hard sells, fake urgency, and watermarked re-uploads.
