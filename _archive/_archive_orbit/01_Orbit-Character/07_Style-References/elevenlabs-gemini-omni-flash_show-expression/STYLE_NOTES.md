**Role:** Animation *look* reference for a possible Orbit rebuild — not a character master.

## What to steal from this look

1. **Cinematic 3D / premium CG** — glossy materials, shallow DOF, soft key light, bokeh backgrounds.
2. **Emotion on the faceplate** — clear expression beats as the primary storytelling device (happy / concerned / curious).
3. **World as science theatre** — lab / observatory desk + big holographic cosmos (planets, orbits, galaxy, data panels) behind the character.
4. **Push-in / close-up punctuation** — wide “in the room” → medium emotional hold → tight faceplate smile.
5. **Warm character vs cool world** — orange robot glow against blue holograms / steel set.

## What *not* to copy

- Claw hands / fingered grippers → keep Orbit stubby side arms.
- LED line / pixel-dot faces → keep Orbit cream eye shapes from the character sheet.
- Drawn mouth variants → avoid etched/LED mouths on Orbit masters.
- German UI gibberish / random HUD text → English chapter cards or no text.
- Character redesign between shots — lock Orbit to the master sheet + Seedance refs.

## Orbit adaptation rule

Same *cinematography + set energy*, different *character lock*:

> Orbit (canonical orange body, black faceplate, cream eyes, single antenna, stubby arms) floats in a soft-lit observatory / science theatre. Behind him, a large holographic solar system and spiral galaxy. Camera: slow push-in. Expression changes only via cream eyes. Premium animated-film CG. No claws, no mouth redesign, no logos, no watermark.
