# Orbit Performance Rig v02

Five identity-consistent transparent performance poses, normalised to a single body anchor on a 580x430 canvas.

- `neutral-left`: default content-focused gaze
- `present-left`: points into the documentary frame
- `thinking-left`: reflective scientific beat
- `amazed`: discovery and scale reaction
- `wave-camera`: direct viewer address

All loops use ProRes 4444 transparency and restrained motion. Position the canvas at one fixed lower-right screen anchor; change pose without changing overlay coordinates.
