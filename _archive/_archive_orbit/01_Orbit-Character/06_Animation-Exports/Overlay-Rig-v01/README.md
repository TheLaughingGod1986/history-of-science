# Orbit Overlay Rig v01

A clean, fixed-canvas Orbit companion for documentary overlays.

- Canonical source: `orbit_rgba_neutral.png`
- Transparent 420x380 ProRes 4444 loop
- 6-second seamless idle with restrained blink and tilt
- Keep at one fixed lower-corner anchor; do not reposition per shot
- Recommended rendered height: about 22% of a 1080p frame
- Hide on text cards, chapter cards, and brand plates
