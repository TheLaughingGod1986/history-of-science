# Orbit Interactive Overlay Repair — v23

## Outcome

Version 23 replaces the intermittent static mascot treatment with a reusable
performance system. Orbit now stays in a consistent lower-right stage position,
looks inward toward the documentary imagery, and changes pose according to the
narration.

## Performance design

- Fixed lower-right anchor with safe margins
- Approximately 15% larger than the prior selective-overlay treatment
- Gentle hover, scale breathing and restrained rotational movement
- Soft fades between performance states instead of scene-to-scene jumps
- Five clean expression/gesture states:
  - neutral watching left
  - presenting left
  - thinking left
  - amazed reaction
  - direct-to-camera wave
- 19 purposeful appearances
- 32 performance segments
- 20.12% total on-screen presence
- No live overlay over the dedicated end-screen card

## Source and preservation

The clean canonical mascot was used as the only character reference. Five new
pose images were generated, keyed to transparency, colour-despilled, normalized
to a fixed body anchor, and converted into reusable transparent ProRes 4444
performance loops.

Earlier broadcast versions, the clean no-Orbit picture bed, raw pose generations
and the original audio mix remain preserved.
