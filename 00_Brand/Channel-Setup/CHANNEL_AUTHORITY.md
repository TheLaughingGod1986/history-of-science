# Channel authority

Set 25 Sep 2026, from Orbit With Ben's version. Cursor rule: `.cursor/rules/hos-studio.mdc`.

Authority is trust that the film is about the thing it says, from the same people, every week.

1. **Picture matches the sentence.** The named person, room and object are on screen when the line names them. The mute test passes.
2. **The history is right.** Every date, name and number is sourced. Where historians disagree, the film says so in one line rather than picking the better story.
3. **The Explorer is the same character.** The locked sheet is `01_Character/01_Master-References/hos-explorer-character-sheet-v01.jpg`. An off-model boy (no glasses, wrong coat, melted face) doesn't ship.
4. **The voice is there.** No silent uploads. Ben Orbit Narrator. The AI disclosure is yes on every upload.
5. **The weekly promise.** One long, three Shorts, the same look and the same voice next week. No second long on a subject that already has one.

Don't schedule a long whose picture fails the match.
