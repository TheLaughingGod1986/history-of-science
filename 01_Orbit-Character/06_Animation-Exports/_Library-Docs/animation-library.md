## Generation workflow

1. Upload `orbit-seedance-reference-v01.png` as sole character reference.
2. Paste matching prompt from `_Prompts/` or Desktop `Orbit-Animation-Library-Pack/prompts/`.
3. Generate 16:9; prefer ≥2 takes when credits allow.
4. QC against rejection list; save raw; polish selected; copy master into category folder.
5. Update `animation-index.csv` status + quality score.

## QC rejection list

Reject: redesign, wrong colours, extra/missing limbs, missing antenna, face/eye distortion, camera shake, morphing, text, watermark, artefacts.
